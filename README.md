# MouseExtend 🖱️✨
> **超轻量 macOS 鼠标左右切屏按键映射小工具**  
> 仅专注于一个核心功能：自由设置鼠标按键与左右切屏的绑定映射，出厂自带最佳默认改键！

---

## 🌟 核心特色与功能

专为需要使用鼠标替代触控板左右横滑切屏的用户打造，极致精简，**仅保留左右切屏改键功能**：

1. **默认智能改键（开箱即用）**：
   - 🖱️ **向左切屏 (上一空间)** ➔ 默认绑定 **按键 4 (侧键后退 Back)**
   - 🖱️ **向右切屏 (下一空间)** ➔ 默认绑定 **按键 5 (侧键前进 Forward)**
2. **直观的交互式按键去绑定**：
   - 点击 **[去绑定按键]**（或 **[重新去绑定]**）；
   - 直接在鼠标上按下任意想要设置的按键（侧键、中键等）；
   - 系统自动捕获并完成绑定，无需辨认复杂的按键代号。
3. **实时按键测试**：
   - 面板内置实时测试验证框，按下鼠标按键即刻显示捕获的按键以及触发的切屏动作。
4. **极致轻量精简**：
   - 纯 Swift 原生打造，常驻右上角菜单栏，内存占用仅约 10MB，0% CPU 占用，极速响应。

## ⚙️ 界面预览说明

点击菜单栏图标 ➔ **「左右切屏按键设置...」**：

- **向左切屏卡片**：显示当前绑定的鼠标按键，点击即可重新按下鼠标按键完成绑定。
- **向右切屏卡片**：显示当前绑定的鼠标按键，点击即可重新按下鼠标按键完成绑定。
- **实时按键测试框**：按下鼠标按键原地检验切屏绑定效果。
- **恢复默认按钮**：一键重置为侧键 4 与侧键 5。
